# 0002：从总体准确率到错误样本分析

## 背景

冻结 backbone 的 ResNet-18 baseline 已经在 CUB 验证集上跑通，验证 top-1 为 24.70%，top-5 为 53.76%。

## 学到什么

总体 accuracy 只能说明模型整体表现，不能解释模型具体错在哪里。科研实验需要进一步导出样本级预测记录，包括真实类别、top-1 预测、top-5 预测和预测概率。

## 为什么重要

错误样本分析能帮助判断下一步方向：

- 如果 top-5 高但 top-1 低，说明表征已有信号，但分类边界还不够好。
- 如果高置信错误集中在相似鸟类，说明模型需要更细粒度的局部特征或更强 backbone。
- 如果错误置信度普遍低，优先考虑训练轮数、学习率和数据增强。
