# VisionSearch-FG Resources

## Knowledge

- [CUB-200-2011 dataset page - Caltech Vision Lab](https://www.vision.caltech.edu/datasets/)
  Official entry point for CUB metadata and downloads. Use for: dataset structure, citation, and file expectations.
- [PyTorch data loading documentation](https://docs.pytorch.org/docs/stable/data.html)
  Official reference for `Dataset`, `DataLoader`, batching, and multiprocessing. Use for: data pipeline design.
- [torchvision transforms documentation](https://docs.pytorch.org/vision/stable/transforms.html)
  Official reference for image preprocessing and augmentation. Use for: train/validation transform choices.
- [torchvision ResNet model documentation](https://docs.pytorch.org/vision/stable/models/resnet.html)
  Official reference for ResNet variants and pretrained weights. Use for: baseline model setup.

## Wisdom (Communities)

- [PyTorch Forums](https://discuss.pytorch.org/)
  High-signal debugging community for PyTorch behavior, tensor shapes, and training issues.
- [Papers With Code: Fine-Grained Image Classification](https://paperswithcode.com/task/fine-grained-image-classification)
  Useful for situating methods and metrics, but not a substitute for reading the original papers.
