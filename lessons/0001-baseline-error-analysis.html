Baseline 错误样本分析

本课的目标是学会从一个分类模型的 checkpoint 中导出样本级证据： 每张图的真实类别、top-1 预测、top-5 预测和置信度。

核心判断

总体 accuracy 只能回答“模型整体对了多少”。错误样本分析回答的是 “模型具体在哪里失败”。这决定下一步是调训练策略、改 backbone，还是加入局部细节分析。 

image -> model -> logits -> softmax -> top-k -> prediction record

你需要记住的 shape

image:  [B, 3, 224, 224]
label:  [B]
logits: [B, 200]
probs:  [B, 200]
top5:   [B, 5]
CUB 有 200 类，随机 top-1 约为 0.5%。如果冻结 backbone 的 baseline 能到 20% 以上， 说明预训练特征已经提供了有效信号。

实践命令

.\.venv\Scripts\python.exe scripts\analyze_baseline_predictions.py `
  --config configs\baseline_resnet18_frozen.yaml `
  --checkpoint outputs\checkpoints\baseline_resnet18_frozen\20260821_200139_baseline_resnet18_frozen\best.pt `
