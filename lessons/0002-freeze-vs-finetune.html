冻结 backbone 与 Fine-tuning

本课的目标是理解迁移学习中的一个核心选择：只训练分类头，还是让整个 backbone 一起更新。

冻结 backbone

backbone.requires_grad = false
classifier.requires_grad = true

这种设置计算成本低，适合先确认数据、标签、训练 loop 和验证指标是否正确。

非冻结 fine-tuning

backbone.requires_grad = true
classifier.requires_grad = true

这种设置会更新更多参数，模型可以适配 CUB 的细粒度鸟类差异，但需要更小学习率和更谨慎的验证。

你需要记住的判断

如果没有先跑通冻结 baseline，就直接 fine-tune，出现问题时很难判断是数据问题、训练问题， 还是优化策略问题。
