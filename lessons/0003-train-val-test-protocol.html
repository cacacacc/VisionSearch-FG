Train / Validation / Test 协议

本课的目标是理解为什么正式实验必须把训练、验证和最终测试分开。

三部分职责

Training:   更新模型参数
Validation: 选择超参数和 best checkpoint
Test:       最终一次性报告泛化结果

CUB 中的正确做法

Official Train 5,994
  -> Training about 4,795
  -> Validation about 1,199

Official Test 5,794
  -> Final Test Only
如果你根据 test accuracy 调参，test set 就已经变成 validation set，最终结果会失去可信度。

实践命令

.\.venv\Scripts\python.exe scripts\create_cub_splits.py --root data\raw\CUB_200_2011 --seed 42
